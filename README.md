# Aldora Calendar Ultra

Premium enterprise calendar and productivity web application built with HTML, CSS, and JavaScript.

## Features
- Month / Week / Day View
- Agenda Management
- Hijri Calendar
- Chinese Zodiac
- Indonesian Holidays
- Drag & Drop Events
- Recycle Bin
- Recurring Events
- Reminder System
- Offline Storage
- ICS Export
- JSON Backup & Restore
- Dark / Light Mode
- Responsive Dashboard

## Technology
- HTML5
- CSS3
- JavaScript
- Local Storage API
- Notification API
